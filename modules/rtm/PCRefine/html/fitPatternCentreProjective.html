function P = fitPatternCentreProjective(PCX,PCY,PCZ,x,y)

Fitting a projective transformation between PCX,PCY,PCZ and xGrid, yGrid vectors

P = fitPatternCentreProjective(PCX, PCY, PCZ, x, y) computes a projective transformation matrix that relates the input projection cetnre coordinates (PCX, PCY, PCZ) to the specified grid vectors (x, y). This function constructs a minimization matrix and solves for the transformation parameters using linear algebra techniques. NOTE: The minimization matrix is only solvable, if at least 5 combinations of PCX,PCZ,PCZ, x and y are known. For more the linear equation is over determined an the best fit is determined by the matlab command.

Inputs: - PCX: Pattern Centre X. - PCY: Pattern Centre Y. - PCZ: Pattern Centre Z. - x: Beam Position on Sample x. - y: Beam Position on Sample y.

Outputs: - P: The projective transformation matrix that aligns the projection center with the sample coordinates.

Usage: PCs = P(1:3,:)*[x;y;ones(size(x))]

   scale = P(10)*x + P(11)*y +1;
   PCs = PCs./scale;
   PCX = PCs(:,1:3);
   PCY = PCs(:,1:3);
   PCZ = PCs(:,1:3);
