Setup our Phases

The specification of the .pha files is in analogy to the default used in
AstroEBSD before. If you want to load a EMsoft Masterpattern saved as a
.h5 file, add the following lines to your .pha file

$sim_type
Emsoft
$dynamic
>yourSimulationFile>.data.h5

If no sim_type is specified, it will be assumed that the simulation
stems from Bruker Dynamics

Let's test it and visulaise the pattern projected to a sphere

Note, that for hexagonal and triognal phases there is currently a range of black dots in positive and negative y direcation at z=0, which is due to some artefacts in the square master patterns themeselves

[x,y,z]=sphere(1000);

[pattern_data] =Cube_Sample(x,y,z,screen_int,RTM_info.isHex);

figure
surf(x,y,z,pattern_data,"EdgeColor","none")
axis equal;
colormap gray;
title(sprintf('Kikuchi Sphere of %s', InputUser.Phase_Input{1}))

Now we can try to plot an EBSD pattern in the gnomonic projection

Build the geometry and define the rotation matrices first

% Euler angles for rotation1
phi1=0;
Phi=90;
phi2=0;
gmatrix1=rotation.byEuler(phi1*degree,Phi*degree,phi2*degree).matrix

% Euler angles for rotation2
phi1=0;
Phi=0;
phi2=0;
gmatrix2=rotation.byEuler(phi1*degree,Phi*degree,phi2*degree).matrix


%Detector size
PatternInfo.ScreenWidth=round(512*1.2);
PatternInfo.ScreenHeight=512;

% Patterncenter, we choose something typical for a 70° EBSD
PatternCentre= [0.5 0.3 0.65]


[ EBSD_geometry ] = EBSP_Gnom(PatternInfo,PatternCentre);

Caluclate the gnomonic projection

[ Pat_sim_eang1] = EBSP_gen( EBSD_geometry,gmatrix1,screen_int,1);%'lattice_scaling',[1 1.1 0.9]);
[ Pat_sim_eang2] = EBSP_gen( EBSD_geometry,gmatrix2,screen_int,1);

Plot the patterns

f=figure;
f.Position=([100 100 800 300])

AxesH=subplot(1,2,1)
imagesc(Pat_sim_eang1)
axis equal;
axis xy;
colormap 'gray';
axis off;
axis(AxesH, 'tight');
title('Gnomonic projection','for Rotation 1')


AxesH=subplot(1,2,2)
imagesc(Pat_sim_eang2)
axis equal;
axis xy;
colormap 'gray';
axis off;
axis(AxesH, 'tight');
title('Gnomonic projection','for Rotation 2')
